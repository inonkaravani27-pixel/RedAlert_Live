# RedAlert Live

> כלי מידע משלים בלבד. אינו תחליף ליישומון הרשמי של פיקוד העורף ואינו מבטיח התרעה מוקדמת או זמן התגוננות.

## קבצים
- `server.js` — שרת Node.js, כולל איסוף דיווחי תקשורת ו-OSINT ציבוריים.
- `index.html` — ממשק עברי מותאם לנייד.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — תמיכה בסיסית בהוספה למסך הבית.
- `render.yaml` — תצורת פריסה ל־Render.

## הפעלה ופריסה
נדרשת Node.js 18 ומעלה. הפעלה מקומית: `npm start`.
ב־Render אפשר לבחור New → Blueprint ולבחור את המאגר. בדקו לאחר הפריסה:
- `/healthz` — צריך להחזיר `{"ok":true,...}`.
- `/api/state` — מצב השרת ומצב מקור התרעות פיקוד העורף דרך ממסר קהילתי.

## משתני סביבה אופציונליים
- `OREF_URLS` — כתובות ממסר התרעות מופרדות בפסיקים. ברירת מחדל: ממסר קהילתי של oref-map.
- `POLL_MS` — תדירות משיכה במילישניות (ברירת מחדל 10000).
- `STALE_MS` — סף סימון מידע כמיושן (ברירת מחדל 45000).
- `PRELIM_RSS_URLS` ו־`PRELIM_KEYWORDS` — פידים ומילות מפתח לדיווחים ראשוניים.
- מקורות OSINT ציבוריים כוללים כרגע את AMK Mapping, Geopolitics Watch ו-Rerum Novarum Intel דרך תצוגות Telegram ציבוריות, לצד חיפוש חדשות ממוקד איראן/הורמוז.
- `MILITARY_RSS_URLS` ו־`MILITARY_KEYWORDS` — פידים ומילות מפתח לחדשות כלליות על פעילות צבאית.
- `MAX_AGE_MS` — גיל מרבי לפריטי RSS (ברירת מחדל 30 דקות).

אין פידי RSS מוגדרים כברירת מחדל. יש לאמת כתובות פיד ותנאי שימוש לפני הוספתן. כתבות ופוסטים אינם התרעות רשמיות ואינם ראיה לשיגור קרוב. אין מעקב לווייני/פיזי אחר מיקום משגרים, אין זיהוי אוטומטי של כל תזוזה, וייתכן שמקורות ציבוריים או גשרי RSS יהיו חסומים או לא זמינים. יש להצליב דיווחי OSINT עם מקור עצמאי.

## בדיקות ומגבלות
הפרויקט לא אומת מול מקור התראות חי או במכשיר פיזי. אם `oref.state` אינו `ok`, אין להציג את המידע כאילו הוא עדכני. התראות Push אינן ממומשות. פעלו תמיד לפי הנחיות פיקוד העורף והיישומון הרשמי.
