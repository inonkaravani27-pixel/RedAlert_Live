# RedAlert Live

> כלי מידע משלים בלבד. אינו תחליף ליישומון הרשמי של פיקוד העורף ואינו מבטיח התרעה מוקדמת או זמן התגוננות.

## קבצים
- `server.js` — שרת Node.js ללא תלויות חיצוניות.
- `index.html` — ממשק עברי מותאם לנייד.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — תמיכה בסיסית בהוספה למסך הבית.
- `render.yaml` — תצורת פריסה ל־Render.

## הפעלה ופריסה
נדרשת Node.js 18 ומעלה. הפעלה מקומית: `npm start`.
ב־Render אפשר לבחור New → Blueprint ולבחור את המאגר. בדקו לאחר הפריסה:
- `/healthz` — צריך להחזיר `{"ok":true,...}`.
- `/api/state` — מצב השרת ומצב המקור Siren.

## משתני סביבה אופציונליים
- `SIREN_URL` — ברירת מחדל `https://api.siren.co.il/active`.
- `POLL_MS` — תדירות משיכה במילישניות (ברירת מחדל 10000).
- `STALE_MS` — סף סימון מידע כמיושן (ברירת מחדל 45000).
- `PRELIM_RSS_URLS` ו־`PRELIM_KEYWORDS` — פידים ומילות מפתח לדיווחים ראשוניים.
- `MILITARY_RSS_URLS` ו־`MILITARY_KEYWORDS` — פידים ומילות מפתח לחדשות כלליות על פעילות צבאית.
- `MAX_AGE_MS` — גיל מרבי לפריטי RSS (ברירת מחדל 30 דקות).

אין פידי RSS מוגדרים כברירת מחדל. יש לאמת כתובות פיד ותנאי שימוש לפני הוספתן. כתבות אינן התרעות רשמיות ואינן ראיה לשיגור קרוב.

## בדיקות ומגבלות
הפרויקט לא אומת מול מקור התראות חי או במכשיר פיזי. אם `siren.state` אינו `ok`, אין להציג את המידע כאילו הוא עדכני. התראות Push אינן ממומשות. פעלו תמיד לפי הנחיות פיקוד העורף והיישומון הרשמי.
